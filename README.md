# 離線會議記錄生成器（GitHub Pages 版）

錄音 → 逐字稿 → 自動整理「討論議題 / 待處理事項（DRI / CP）/ 待確認事項」。
所有錄音與會議內容只存在你自己的手機或電腦，網站上只有工具本身。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 工具本體 |
| `sw.js` | 離線快取（第一次連網打開後，之後沒網路也能用） |
| `manifest.webmanifest` | 讓手機可以「加入主畫面」像 App 一樣開啟 |
| `icon-192.png`、`icon-512.png`、`apple-touch-icon.png` | 主畫面圖示 |

## 一、架設步驟（全部在網頁上操作，不用安裝軟體，約 10 分鐘）

### 1. 申請 GitHub 帳號
到 https://github.com/signup 註冊（只需要 Email）。
帳號名稱會出現在網址裡，例如帳號 `ming-tpm` → 網址是 `https://ming-tpm.github.io/...`

### 2. 建立專案（Repository）
1. 登入後點右上角 **＋** → **New repository**
2. **Repository name** 填：`minutes`（之後網址就是 `.../minutes/`）
3. 選 **Public**（免費帳號的 Pages 必須是 Public；只公開工具程式碼，不含任何會議資料）
4. 其他不用勾，按 **Create repository**

### 3. 上傳檔案
1. 在新專案頁面點 **uploading an existing file**（或 **Add file → Upload files**）
2. 把這個資料夾裡的 **7 個檔案全部拖進去**（index.html、sw.js、manifest.webmanifest、3 個 png、README.md）
3. 拉到下方按 **Commit changes**

### 4. 開啟 GitHub Pages
1. 專案頁上方點 **Settings** → 左側選單點 **Pages**
2. **Source** 選 **Deploy from a branch**
3. **Branch** 選 **main**，資料夾選 **/ (root)** → 按 **Save**
4. 等 1～2 分鐘，重新整理頁面，上方會出現網址：
   `https://你的帳號.github.io/minutes/`

## 二、iPhone 使用方式

1. 用 **Safari** 打開上面的網址（需要連網，第一次）
2. 點下方 **分享按鈕（方框加箭頭）** → **加入主畫面** → **新增**
3. 之後從主畫面的「會議記錄」圖示打開即可，**沒網路也能用**
4. 第一次按「開始錄音」時，允許使用麥克風

**iPhone 注意事項**
- 錄音時請**保持畫面開著**：鎖屏或切到其他 App，錄音會中斷（工具會自動讓螢幕不關閉）
- 錄音檔格式是 `.m4a`，按「下載錄音檔」會存到「檔案」App
- 太久沒打開（數週），iPhone 可能清掉暫存資料；從主畫面圖示開啟比較不會被清
- 「同步即時轉文字」在 iPhone 上可能會用到 Apple 的伺服器；機密會議請取消勾選，或開飛航模式

## 三、匯入錄音檔轉文字

收音不好、或想用手機內建錄音 App 錄音時，用這個功能把錄音檔轉成逐字稿。

1. 按「選擇錄音檔」，選 m4a / mp3 / wav / webm 檔（iPhone 語音備忘錄：分享 → 儲存到檔案，再回來選）
2. 第一次使用會下載語音模型（標準約 80MB），**這一次要連網**；下載完成後這台設備就能離線轉文字
3. 轉完後檢查逐字稿，再按「產生會議記錄」

**注意**
- 錄音檔只在你的設備上處理，不會上傳
- 轉文字需要時間：電腦大約是錄音長度的 1/5～1 倍，手機會更慢；一小時以上的會議建議用電腦轉
- 模型下載來源是 Hugging Face，大陸網路連不上時會自動改用鏡像站（hf-mirror.com）；兩邊都連不上就要翻牆或換網路
- 中文會議轉出來可能是簡體字，不影響整理結果
- 剛錄完的會議可以直接按「用剛剛的錄音轉文字」

## 四、電腦使用方式

用 Chrome 或 Edge 打開同一個網址即可。Chrome 網址列右側如果出現「安裝」圖示，可以安裝成桌面 App。

## 五、更新工具

拿到新版 `index.html` 時：專案頁 → **Add file → Upload files** → 拖入新檔案 → **Commit changes**。
手機和電腦下次**連網打開**時會自動換成新版。

## 常見問題

**Q：網址打不開？**
github.io 在中國大陸連線不穩定，可能需要翻牆；公司網路也可能擋 GitHub。可以先在有網路的地方打開一次並「加入主畫面」，之後就能離線使用。

**Q：別人看得到我的會議內容嗎？**
看不到。網站上只有工具程式碼；錄音、逐字稿、會議記錄都只存在你自己的裝置瀏覽器裡。

**Q：公司規定可以放 GitHub 嗎？**
工具本身不含公司資料，但建議先確認公司對「把工作工具放到公開網站」的規定。
